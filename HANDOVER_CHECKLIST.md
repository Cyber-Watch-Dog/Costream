## 🐛 Quick Troubleshooting for Demo

### If Video Won't Play
1. Use correct video URL format
2. Try: `https://commondatastorage.googleapis.com/gtv-videos-library/sample/BigBuckBunny.mp4`
3. Check browser console for errors

### If Sync Not Working
1. Verify both users in same room ID
2. Check Socket.IO connection (F12 → Network)
3. Refresh browser
4. Try play/pause again

### If Chat Not Working
1. Check browser console for JS errors
2. Verify Socket.IO connected
3. Check terminal for Flask errors
4. Refresh page

### If Port 5000 Busy
1. Terminate other Flask processes
2. Or change port in app.py last line
3. Restart with new port
